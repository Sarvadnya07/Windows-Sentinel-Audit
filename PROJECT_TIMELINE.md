# Roadmap & Project Timeline

## Completed Milestones

### v1.0 - Core Audit (Current)

- Basic Process, Network, Service, and Persistence audits.
- Centralized WMI caching.
- Correlation and Risk Engines.
- HTML, JSON, and CSV outputs.

## Future Milestones

### v1.1 - Deep Inspection

- **Scheduled Tasks Audit:** Parse XML definitions for encoded commands.
- **WMI Persistence Audit:** Enumerate event filters and consumers.
- **Driver Audit:** Enumerate loaded `.sys` files.

### v2.0 - Enterprise Features

- **YARA Integration:** Evaluate suspicious process artifacts with rules.
- **ETW Telemetry:** Subscribe to Event Tracing for Windows events.

### v3.0 - Fleet Aggregation

- **Cloud Dashboard:** Aggregate audit results from multiple endpoints
  and support cross-host frequency analysis.
