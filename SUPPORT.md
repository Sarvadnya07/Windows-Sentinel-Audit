# Support

If you need help using SystemWide-AbuserHunter, please consult the documentation in the `Docs/` directory first.

If you encounter a bug or have a feature request, please [open an issue](https://github.com/yourorg/SystemWide-AbuserHunter/issues) using the provided templates.

For community discussion, DFIR analysis tips, and heuristic sharing, please utilize GitHub Discussions.
